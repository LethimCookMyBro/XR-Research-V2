# PBR texture sources (CC0)

Downloaded 2026-09-29 for the visual-quality pass; resized and repacked for URP Lit
(`_Mask`: R=metallic, G=occlusion, A=smoothness=1-roughness). `PBR_PaintedPlaster` and `PBR_PaintedMetal` albedo
are desaturated so each material's `_BaseColor` sets the paint colour.
