## Handoff rules

The Blender glTF exporter recognizes supported material node arrangements rather than copying arbitrary Blender shader graphs. Bake procedural appearance or deliberately recreate it in Unity. See [Blender 5.2 glTF material documentation](https://docs.blender.org/manual/en/5.2/addons/scene_gltf2.html#materials).

URP Lit supports metallic/specular workflows and opaque/transparent surfaces. Set the target material mode explicitly; transparent objects use a separate pass and require sorting review. See [Unity 6 / URP Lit material reference](https://docs.unity3d.com/6000.0/Documentation/Manual/urp/lit-shader.html). This reference is guidance, not proof that the target project uses Unity 6.

## Important groups

- Glass: inspect transmission/opacity, render ordering, backface culling and reflections after import; use a simple transparent URP material if that is the accepted target look.
- Factory/room floors: inspected materials may be constant PBR rather than procedural. Preserve their numeric values; validate smoothness, tiling and lighting in Unity.
- Painted metal/workbench surfaces: retain material boundaries. Oak procedural detail needs baking/recreation; metallic is not a substitute for a painted dielectric surface.
- Vehicles: keep vehicle materials with the independently disableable vehicle module. Validate clear-coat, window/lens transparency and normal maps.
- Plants: verify alpha clipping only when source alpha is actually connected; inspect both leaf sides. Opaque source leaves are not automatically alpha vegetation.
- Observed source specifics: FactoryFloor, Floor and TrainingFloor use constant Principled inputs. Oak and Wall have connected Noise Texture detail. potted_plant_02_leaves uses alpha; potted_plant_04 does not. R03_SmokedGlass and glass_surr are opaque by their connected inputs despite their names; preserve that accepted intent.
- Emission and scene lights: exported material emission does not establish equivalent lighting. Validate baked/realtime lighting and reflection probes in the Unity project.
- Texture images: the JSON records packed/external presence, resolution, color space and node links. Repack/reassign channels as required by the chosen importer; source packed images alone do not prove successful GLB embedding.

## Required checks after Unity import

1. Record Unity/URP/importer versions and supported glTF extensions.
2. Compare all ten accepted review viewpoints: base colors, roughness/smoothness, normal orientation, glass, plant silhouettes and vehicle paint.
3. Verify texture import color spaces, normal-map type and channel packing; inspect alpha cutoff and both-sided geometry.
4. Check lighting/reflection setup, transparent overdraw, material/renderer counts and actual target-device frame timing.
5. Keep procedural baking/recreation as an explicit remaining appearance task; do not treat successful GLB reopening as visual parity.
