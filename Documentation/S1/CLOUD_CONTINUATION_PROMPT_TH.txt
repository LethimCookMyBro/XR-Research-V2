12. วิธีทำและส่งมอบ:
ทำbatchเล็ก reproduce→patch→focused tests→เปิดภาพ/พฤติกรรมจริงเมื่อมีเครื่องมือ→regression→commitและpushเข้าmainตามสิทธิที่ได้รับ

ไม่วนสร้างแกลเลอรี/รายงาน/เครื่องมือวัดแทนปิดfunctionality
ก่อนจบทุกbatchอ่านdesign_ruleและissue ledgerซ้ำ ปิดเฉพาะข้อที่มีหลักฐาน
ส่งสถานะเดียวที่บอกทำอะไรได้เพิ่ม ไฟล์ที่เปลี่ยน ผลทดสอบ งานค้าง และขั้นทดสอบlocalที่ทำตามได้
ต้องเหลือเฉพาะขั้นที่ใช้เครื่องมือ/คนที่ไม่มีจริง ไม่ใช่งานโค้ดที่ยังไม่ทำแล้วเรียกว่ารอผู้วิจัย
ผู้ใช้อนุญาตให้รวมและส่งงานปัจจุบันเข้าmainแล้ว ข้อความเก่าที่ห้ามmergeเข้าmainหรือบังคับbranchแยกถูกแทนด้วยกติกานี้
ไม่force-push ไม่ล้างworking treeของเครื่องlocal ตรวจและรวมงานใหม่ที่ชนกันก่อนpush และไม่รับรองโปรแกรม100%โดยไม่มีหลักฐาน
เริ่มอ่านจุดรับช่วงแล้วลงมือ fixed UI + Training/Reader bugs ที่ยืนยันได้ก่อน ไม่ตอบเพียงแผน
