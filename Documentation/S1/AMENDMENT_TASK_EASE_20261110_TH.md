สถานะ: Engineering amendment ตามคำสั่งและคำตัดสินของเจ้าของงาน 10 พ.ย. 2026 **ยังไม่ได้รับอนุมัติจากอาจารย์ ยังไม่ผ่านผู้สวม Quest**
ใช้กับ session ใหม่เท่านั้น session ที่บันทึกแล้วคง version เดิม ไม่ย้ายข้อมูลย้อนหลัง สเปก `VR_TaskSpec_S1_LOCKED_TH.md` ไม่ถูกแก้

## ข้อที่ต่างจากสเปก S1 ที่ล็อกไว้
สเปกข้อ 5.2 กำหนดว่า "สาย data หนึ่งเส้นปลายบอร์ดเชื่อมอยู่, สายไฟ SATA และ PCIe ปลาย PSU เชื่อมอยู่"
เจ้าของงานตัดสินเมื่อ 10 พ.ย. 2026 ให้ **ถอดสายทั้งสามเส้นออกทั้งเส้น ผู้เข้าร่วมเสียบเองทั้งสองปลาย** (6 จุดเสียบ แทน 3)
ข้อนี้เพิ่มขั้นตอนและเวลาของ Task A จึงต้องให้อาจารย์อนุมัติก่อนใช้กับ Study

## สิ่งที่ไม่เปลี่ยน
- ผู้เข้าร่วมยังต้องเลือกและติดตั้ง RAM 2 แผง SSD 1 ชุด GPU 1 ใบ และกด "ตรวจผลงาน" เอง
- ตัวเลือกชิ้นส่วน ฉลาก ข้อกำหนด W2 เกณฑ์ผ่าน และข้อความผลตรวจ ชิ้นที่ใส่ได้ทางกลแต่ไม่ตรง W2 ยังใส่ได้
- หัวต่อปลายอุปกรณ์ ค่าความคลาดเคลื่อนของการเสียบ สลักหัว PCIe และกฎหัวกลับด้าน/ผิดชนิดของ SATA
- ความยาวสาย รัศมีโค้งต่ำสุด และกฎ `CableLimit`
- สถานะชุดฐานในข้อมูล (`atx24Connected`, `epsConnected`, `cpuFanConnected`, `frontPanelConnected`, `powerIsolated`) ยังเป็นจริงเหมือนเดิม แม้สายชุดฐานไม่แสดงแล้ว
- เพดาน 420 วินาที
- Task B: ขั้นตอน สาเหตุผิดปกติ (B04 ตัวล็อกตะแกรงหลังขันไม่สุด) และเกณฑ์ผ่านเหมือนเดิม

## ผลต่อ Protocol, H1–H4 และความยาก
- **Task A มีขั้นตอนเพิ่ม**: จุดเสียบสายเพิ่มจาก 3 เป็น 6 และต้องรู้ว่าปลายต้นทางเสียบช่องชนิดใดของบอร์ด/PSU ส่วนการลอดสายไปด้านหลังและการตามหาหัวสายที่หลุดมือหายไป ผลรวมต่อเวลา Task ยังไม่ได้วัดกับคนจริง
- **ผล Inspect**: สายที่ปลายต้นทางยังไม่เสียบให้ผล "ยังประกอบหรือต่อสายไม่ครบ" เหมือนสายที่ปลายอุปกรณ์ยังไม่เสียบ สภาพเริ่มต้นจึงมีสายที่ยังไม่ต่อทั้งสองปลาย
- **นิยาม H1–H4 เดิม** event `GRAB`, `ACTION` (CONNECT/DISCONNECT/MOVE), `INSPECT` เหมือนเดิม มี target ใหม่ของหัวต้นทาง: `A.sata_data_board`, `A.sata_power_psu`, `A.pcie_power_psu`
- **ข้อมูลที่เทียบข้าม version ไม่ได้**: จำนวน GRAB/ACTION ของสาย เวลาช่วง SSD/GPU ของ Task A และจำนวน GRAB/ACTION ของ `B.front_guard_clip` การวิเคราะห์ต้องแยกตาม `layout_version` ห้ามรวม session ของ layout เก่ากับใหม่ใน cell เดียวกัน
- การเคลื่อนของหัวสายหลังปล่อยมือเป็นการกลับถาดโดยระบบ ไม่ใช่การกระทำของผู้เข้าร่วม event `PANEL_PLACEMENT*` เป็น source `System` อยู่แล้ว
- ไม่มีผลต่อ Training หรือลำดับ AB/BA

## สื่อข้อมูลอ้างอิง Task A รุ่น A8
แพ็กเกจ A8 (Manual, Step-by-step, Infographic, Video ไทย/ญี่ปุ่น) สร้างจากฉากปัจจุบัน ลำดับขั้น รหัสขั้น (23 ขั้น) และหน่วยสาระ (A17) เท่ากับ A7 ทุกข้อ ที่เปลี่ยนคือ
- ขั้น `A.start`, `A.base`: ไม่พูดถึงสายของชุดฐาน บอกว่าสายที่ต้องต่อเองสามเส้นอยู่บนถาดข้างเคส
- ขั้น `A.ssd.data`, `A.ssd.power`, `A.gpu.power`: หยิบหัวสายจากถาด เสียบปลายหนึ่งที่บอร์ด/PSU อีกปลายที่ SSD/การ์ด หัวที่ไม่ตรงชนิดเสียบไม่เข้า หัวที่ปล่อยกลางทางกลับถาด
- คู่มือ: หน้า SSD, GPU, "ชิ้นส่วนที่ต้องคงไว้" และข้อแก้ปัญหาเรื่องหัวสายเสียบไม่เข้า
- ภาพทุกภาพถ่ายใหม่จากฉากปัจจุบัน ภาพของขั้นต่อสายแสดงสองปลายในภาพเดียว วิดีโอสามบทของสายแสดงการหยิบจากถาด ช่องบนบอร์ด/PSU และช่องที่ SSD/การ์ด เสียงบรรยายห้าบทที่ข้อความเปลี่ยนทำใหม่ด้วยเสียงเดิม
- A7 ไม่ถูกแก้ ยังอยู่ครบสำหรับ session ของ layout เก่า
ข้อความญี่ปุ่นและอังกฤษของ A8 เป็นร่างทางวิศวกรรม ยังไม่มีผู้ตรวจ

## ต้องอนุมัติโดยมนุษย์
- อาจารย์: การให้เสียบสายเองสองปลาย (ต่างจากสเปกข้อ 5.2) การคืนหัวสายเข้าถาด การวาดเส้นทางสายโดยระบบ การไม่แสดงสายของชุดฐาน และเนื้อหา A8
- เจ้าของงาน: ฝาข้างเคสสองแผ่นกลับมาอยู่ในฉากแล้ว ตั้งพักไว้ที่มุมหลังของโต๊ะตามตำแหน่งที่เคยสร้างไว้ ต้องดูว่าตำแหน่งนี้ใช้ได้หรือไม่
- ผู้สวม Quest: หยิบสายจากถาด เสียบช่อง PSU/บอร์ด หมุนเคส เสียบที่ SSD ปล่อยหัวสายแล้วกลับถาด; เปิด/ปิดคลิปด้วย Trigger และจับตะแกรงด้วย Grip ใกล้คลิป; แผงงานที่สถานีพัดลมไม่กะพริบ
- ผู้ตรวจภาษาญี่ปุ่น: ข้อความใหม่ของสื่อ A8
