สถานะ: เจ้าของงานวิจัยอนุมัติในหลักการเมื่อ 2 พ.ย. 2026 (I1–I3, I7, I9 ใน `INFORMATION_AND_CLARITY_PROPOSAL_20261102_TH.md`)
ข้อความไทยและญี่ปุ่นทั้งหมดในเอกสารนี้เป็นร่างจาก AI ยังไม่ได้ให้มนุษย์ตรวจ (`participant_text_version` = `S1_PARTICIPANT_TEXT_CLARITY_20261102_AI_DRAFT`)

ไฟล์ `VR_TaskSpec_S1_LOCKED_TH.md` ไม่ได้แก้ เอกสารนี้บันทึกเฉพาะถ้อยคำที่เปลี่ยน สำหรับ session ใหม่เท่านั้น ส่วน session เก่าแยกได้จาก version ใน log

## สิ่งที่ไม่เปลี่ยน

- ข้อกำหนด W2 ตัวเลือก RAM/SSD/GPU เกณฑ์ Pass/Fail ของ Task A/B และจุดเสียของ Task B
- ลำดับการทำงานยังอิสระ ผู้เข้าร่วมเลือกเองว่าจะเปิดข้อมูลอ้างอิงเมื่อไรและแบบไหน
- ไม่มีคำใบ้อัตโนมัติ ผลตรวจยังไม่บอกว่าผิดที่ชิ้นไหน
- ข้อมูลที่บันทึกยังเหมือนเดิม และเพิ่ม field version กับค่า operation ใหม่ 2 ค่า (ดูท้ายเอกสาร)

ข้อความเต็มตาม spec ยังอยู่ในหน้าแรกของข้อมูลอ้างอิงทุกแบบ ส่วนแผงโจทย์แสดงได้ 2 บรรทัดเท่านั้น

| | ไทย | ญี่ปุ่น |
|---|---|---|
| Task A ชื่อ | ประกอบคอมพิวเตอร์ W2 | W2 のパソコンを組み立てる |
| Task A แผง | ประกอบคอมพิวเตอร์ให้ตรงข้อกำหนด W2 แล้วกด “ตรวจผลงาน” / ข้อกำหนดและวิธีประกอบอยู่ใน “ข้อมูลอ้างอิง” | W2 の要件に合わせて組み立て、「仕上がりを確認」を押します。／要件と取り付け方は「参照資料」にあります。 |
| Task B แผง | ซ่อมพัดลม F2 ที่สั่นหรือมีเสียงกระทบ แล้วกด “ตรวจผลงาน” / เลือกตรวจตะแกรงหน้า ใบพัด หรือตะแกรงหลังก่อนก็ได้ วิธีตรวจและซ่อมอยู่ใน “ข้อมูลอ้างอิง” | 振動や当たる音がする扇風機 F2 を直し、「仕上がりを確認」を押します。／前ガード・羽根・後ガードのどこから調べてもかまいません。調べ方と直し方は「参照資料」にあります。 |

I3: แผงโจทย์ Task A ไม่บอกจำนวน "RAM 2 แผง, SSD 1 ชุด, GPU 1 ใบ" แล้ว จำนวนและตัวเลข W2 ยังมีครบในข้อมูลอ้างอิงทั้ง 4 แบบ (`build.py check`: A 17/17)

## ขอบเขตงานและการตรวจ (I1)

คืน essential unit `scope` ของ Task B (B 19/19) และความหมายเรื่องไฟ, OS และฝาเคสใน `base` ของ Task A แล้ว โดยไม่ใช้ประโยค "ไฟถูกตัดแล้ว" ลอยๆ

- Task A: "ระหว่างประกอบเครื่องไม่มีไฟเข้า เมื่อกด “ตรวจผลงาน” ระบบจะจำลองการเปิดเครื่อง 3 วินาที งานจบเมื่อพร้อมทดสอบ ไม่ต้องลงโปรแกรมหรือปิดฝาเคส"
- Task B: "ระหว่างซ่อม พัดลมไม่มีไฟเข้าและไม่หมุน งานนี้ซ่อมเฉพาะตะแกรง ใบพัด และตัวยึด ส่วนฐาน เสา และหัวพัดลมที่มีมอเตอร์ยึดไว้แล้ว ไม่ต้องถอดหรือเปิด"

## ข้อความระหว่างทำงาน (I9: F2, F4, F7)

- F2: เมื่อมือเข้าใกล้ชิ้นที่จับได้ แผงงานจะแสดงชื่อชิ้นและปุ่มที่ใช้ ก่อนจับ ทุกชิ้นแสดงแบบเดียวกัน รวมทั้งตัวเลือกที่ไม่ตรง W2 และไม่ได้บอกว่าชิ้นไหนถูก การเข้าใกล้ไม่ได้ลงบันทึกใน log
- F4: ขณะหมุนสกรู ฝาล็อก หรือวงแหวน จะแสดง "กำลังขันเข้า" หรือ "กำลังคลายออก" ตามสถานะเกลียวจริง และถ้าหมุนต่อไม่ได้จะแสดง "หมุนต่อไปทางนี้ไม่ได้แล้ว" ไม่มีเปอร์เซ็นต์
- F7: สลักและคลิปรับทั้ง Trigger และ Grip ตามที่ระบบรองรับจริง ข้อความจึงเปลี่ยนเป็น "กด Trigger หรือ Grip หนึ่งครั้งเพื่อเปิดหรือปิด"
