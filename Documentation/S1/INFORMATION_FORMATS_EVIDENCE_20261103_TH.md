# หลักฐานทางวิชาการสำหรับข้อมูลอ้างอิง 4 แบบ (3 พ.ย. 2026)

เอกสารนี้แยก 3 อย่างออกจากกันชัดเจน
- **[บทความ]** สิ่งที่บทความเขียนไว้จริง พร้อมหน้าหรือหัวข้อ
- **[ออกแบบ]** การตัดสินใจของทีมเราที่อาศัยหลักนั้น
- **[ไม่มีหลักฐาน]** สิ่งที่บทความไม่ได้สนับสนุน

## สรุปข้อสำคัญ

- **ไม่มีบทความใดในชุดนี้ทดลอง 4 รูปแบบแบบที่เราใช้** (คู่มือ PDF, ทีละขั้นตอน, ภาพประกอบ, วิดีโอ ให้ผู้เข้าร่วมเลือกเองใน VR)
- Dorloh et al. เปรียบเทียบ 3 แบบ คือคู่มือพิมพ์, วิดีโอ และ AR แต่ละกลุ่มใช้ได้แบบเดียว ไม่ได้ให้เลือก
- Villar & León เปรียบเทียบ ไม่มีข้อมูล / วิดีโอ / ข้อความ / ข้อความกับวิดีโอ ใน tutorial ของ VR
- Klimant & Kollatsch เป็นงานออกแบบระบบสร้างเอกสาร AR ไม่ใช่การทดลองกับผู้ใช้
- S-AID ผมเข้าถึงได้เฉพาะบทคัดย่อ ฉบับเต็มดาวน์โหลดไม่ได้ (ScienceDirect มี bot check และ IRIS ตอบ 403) ข้อความทั้งหมดของแถว S-AID จึงอิงบทคัดย่ออย่างเดียว

## หลักที่นำมาใช้กับแต่ละ format

| format | หลัก | ที่มา |
|---|---|---|
| คู่มือ PDF (ค้นและเปรียบเทียบ) | โครงข้อมูลของงานซ่อมบำรุง มีชื่องาน คำอธิบาย หมายเหตุ เครื่องมือ checklist และเตือนความปลอดภัย จัดเป็นหัวข้อให้ค้นได้ | **[บทความ]** Klimant §4.1 p3–p4 **[ออกแบบ]** เลือกจัดเป็นหน้าอ้างอิงต่อบริเวณ แทนการจัดเป็นลำดับขั้น |
| คู่มือ PDF | คู่มือพิมพ์ที่มีข้อความ + ภาพชี้ตำแหน่ง ใช้กับงานประกอบคอมของมือใหม่ได้ โดยเวลาไม่ต่างจากวิดีโอ | **[บทความ]** Dorloh p5, p10 **[ไม่มีหลักฐาน]** บทความไม่ได้เทียบคู่มือแบบ "ค้นหา" กับแบบ "ทีละขั้น" |
| ทีละขั้นตอน (ทำทีละงาน) | ข้อความเหมาะกับแนวคิดหรือการกระทำที่ผู้ใช้ยังไม่เคยทำ | **[บทความ]** Villar §9 p24 **[ออกแบบ]** ทำ 1 การ์ดต่อ 1 งาน และใส่ผลที่ควรเห็นท้ายการ์ด |
| ทีละขั้นตอน | ผู้ทำงานมือใหม่อ่าน SOP ทีละขั้น | **[บทความ]** Dorloh p2 |
| ภาพประกอบ (ตำแหน่งและสภาพ) | ภาพถ่ายที่ชี้ตำแหน่งสกรูและจุดต่อสายช่วยหาตำแหน่งได้ | **[บทความ]** Dorloh p5 (Figure 4) **[ออกแบบ]** เพิ่มลูกศรทิศทางและภาพคู่ปกติกับผิดปกติ ส่วนนี้ไม่ได้มาจากบทความ |
| ภาพประกอบ | ภาพและ checklist ใช้บรรยาย "สภาพปัจจุบัน" ของเครื่องได้ | **[บทความ]** Klimant §4.1 p3 |
| วิดีโอ (การเคลื่อนไหวจริง) | วิดีโอเหมาะกับการอธิบายการกระทำที่เป็นรูปแบบต่างจากที่เคยฝึก และ "สิ่งที่เกิดตามมา" | **[บทความ]** Villar §3 p5 (hypothesis) และ §9 p24 |
| วิดีโอ | วิดีโอที่ไม่มีเสียงและไม่มีข้อความเป็นข้อจำกัดที่ผู้เขียนยอมรับเอง | **[บทความ]** Dorloh p14–p15 **[ออกแบบ]** วิดีโอของเราจึงมีเสียงบรรยายไทยและญี่ปุ่น |
| ทุก format | การให้ข้อความและวิดีโอพร้อมกันไม่ได้ช่วยเพิ่มอย่างมีนัยสำคัญ | **[บทความ]** Villar §9 p24 **[ออกแบบ]** ให้แต่ละ format มีหน้าที่ต่างกัน แทนการเอาข้อความเดียวกันมาแปะทุก format |
| ทุก format | ข้อมูลชนิดเดียวกันควรถูกกำหนดว่าสื่อด้วยรูปแบบไหน เพื่อลดความซ้ำซ้อนและความไม่สอดคล้อง | **[บทความ]** S-AID (บทคัดย่อเท่านั้น) **[ไม่มีหลักฐาน]** ยังยืนยันรายละเอียดของ taxonomy ไม่ได้ |

## สิ่งที่ห้ามอ้าง

- ห้ามอ้างว่างานใดพิสูจน์แล้วว่า "4 แบบนี้" เหมาะกับ VR maintenance
- ห้ามอ้างว่าวิดีโอทำให้ผิดน้อยกว่าคู่มือ (Dorloh: วิดีโอกับคู่มือไม่ต่างกันอย่างมีนัยสำคัญ)
- ห้ามอ้างรายละเอียดของกรอบ S-AID จนกว่าจะได้อ่านฉบับเต็ม

## สิ่งที่ต้องทำต่อ

- ขอฉบับเต็มของ S-AID ผ่านห้องสมุดมหาวิทยาลัย แล้วเพิ่มหน้าอ้างอิง
- ให้อาจารย์ตรวจว่าการตีความ "descriptive / explanative" ของ Villar ใช้กับงานซ่อมได้หรือไม่
