# ตารางออกแบบ: essential unit → วิธีนำเสนอใน 4 format (3 พ.ย. 2026)

หน้าที่ของแต่ละ format ล็อกไว้แล้ว: **คู่มือ (PDF)** = ค้นและเปรียบเทียบ · **ทีละขั้นตอน** = ลงมือทีละงาน · **ภาพประกอบ** = ตำแหน่ง จุดจับ ทิศทาง สภาพ · **วิดีโอ** = การเคลื่อนไหวจริงพร้อมเสียงบรรยาย

ทุก format ต้องมี unit ครบ แต่ใช้ข้อความหรือหน้าตาต่างกันได้ ทุก format เปิดด้วยสารบัญหัวข้อเดียวกันและไม่บังคับลำดับ หลักที่อ้างอิงอยู่ใน `INFORMATION_FORMATS_EVIDENCE_20261103_TH.md`

ตัวย่อหลัก
- K = Klimant & Kollatsch §4.1 (โครงข้อมูลงานซ่อมบำรุง)
- D = Dorloh et al. p5 (ข้อความ + ภาพชี้ตำแหน่ง, วิดีโอไม่มีเสียง)
- V = Villar & León §9 (ข้อความสำหรับสิ่งใหม่ วิดีโอสำหรับการกระทำ ซ้อนกันไม่ช่วย)
- O = การออกแบบของเรา ไม่มีหลักฐานโดยตรง

การตรวจว่ามี unit ครบ (โดย `build.py check` + ตาราง unit ที่ script สร้าง) **แยกจาก** การตรวจว่าผู้ใช้เข้าใจ (pilot ที่ยังรอการอนุมัติจริยธรรม)
