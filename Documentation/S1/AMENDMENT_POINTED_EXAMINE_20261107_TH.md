- `EXAMINE` / `EXAMINE_REJECTED` ยังเขียนผ่าน task port เดิมด้วย target id เดิม: Task A เป็นรหัสชิ้นจริง (เช่น S01), Task B เป็นบริเวณ S1 (`B.front_guard`, `B.blade_mount`, `B.rear_guard_mount`) ชี้ใบพัด/ฝาล็อกนับเป็น `B.blade_mount`, ชี้ตะแกรงหลังหรือตัวล็อกนับเป็น `B.rear_guard_mount`, ชี้คลิปตะแกรงหน้านับเป็น `B.front_guard`

## ผลต่อข้อมูลที่ต้องรู้
- การชี้ไม่ทะลุชิ้นส่วนที่บังอยู่: เมื่อตะแกรงหน้ายังอยู่ ผู้เข้าร่วมชี้ใบพัดไม่ได้ (ชี้แล้วได้ตะแกรงหน้า) ดังนั้น `EXAMINE_REJECTED` จะเกิดน้อยมากเมื่อเทียบกับเมนูเลือกบริเวณ ส่วนขยาย EXAMINE_REJECTED ของ H4 จึงมีข้อมูลน้อยลง ต้องรายงานแยกตาม examine_version ห้ามรวมกับ session ที่ใช้เมนู
- ตะแกรงหลังตรวจจากภายนอกตาม S1: จากด้านหน้าตะแกรงหน้าบัง ผู้เข้าร่วมต้องก้าวไปด้านข้างพัดลม (ทดสอบเชิงเรขาคณิต: มองเห็นได้ครบที่ 90° และบางส่วนที่ 70°) ไม่ต้องเอื้อมทะลุตะแกรง พฤติกรรมเดินไปด้านข้างถูกบันทึกใน movement
- การ์ดใหญ่ลอยจากชิ้นส่วนใน Task ถูกนำออก ใน Training ชิ้นฝึกกลางยังใช้ป้ายแบบเดิม
