## A. ข้อความโจทย์ Task A/B ที่เสนอใช้จริง

**[หลักฐาน]** แผงโจทย์ (Main panel) แสดงได้ 2 บรรทัดเท่านั้น (`ResearchFlowView.LayoutTaskBrief` วนแค่ 2 แถว ถ้ามีบรรทัดเดียวจะ crash ซึ่งตรวจพบเมื่อ 2 พ.ย.) ข้อความเต็มตาม spec §5.1/§6.1 จึงต้องไปอยู่ที่หน้าก่อนเริ่มจับเวลา และที่หน้าแรกของข้อมูลอ้างอิงทุกแบบ

**[ข้อเสนอ]** แบ่งข้อความเป็น 5 ส่วนตามที่เจ้าของงานกำหนด (Q18) คือ งาน, ชิ้นส่วนที่ใช้, ชิ้นส่วนที่เตรียมไว้แล้ว, วิธีที่ระบบตรวจ และข้อควรรู้ แผงโจทย์แสดงแค่ชื่อกับบรรทัด "งาน" ย่อ ส่วนข้อความเต็มอยู่ที่หน้าเริ่มงาน

## G. แผนตรวจรับ

### G1. ตรวจภาษา (Q19)

- ผู้ตรวจภาษาละ 1 คน (ยังไม่ระบุชื่อ) ใช้ตาราง unit จาก G4 ตรวจความหมาย ตัวเลข ทิศหมุน ชื่อปุ่ม และคำว่า อย่างน้อย / ไม่เกิน / เท่ากับ / จำนวน
- ตรวจข้อความ UI ทั้งหมดด้วย ไม่ใช่แค่ข้อมูลอ้างอิง (ไฟล์ export ของ `ResearchStrings.cs` มี 481 แถว ในนั้นเป็นข้อความที่ผู้เข้าร่วมเห็นประมาณ 300 แถว)
- ภาษาญี่ปุ่นต้องเป็นภาษาธรรมชาติ ไม่ใช่แปลตรงจากไทย ถ้าผู้ตรวจไม่ได้อ่านทั้งสองภาษา ให้ตรวจเทียบความหมายผ่านภาษาอังกฤษในตารางอีกรอบ
- เก็บผลตรวจเป็นไฟล์แยก ห้ามบันทึกว่ามนุษย์ตรวจแล้วจากผลแปลของ AI

### G2. Pilot (Q20)

- ภาษาละ 2–3 คน ที่ไม่เคยเห็นเฉลยและไม่ได้เป็นผู้เข้าร่วมในการศึกษาหลัก
- **ก่อนเริ่ม** ต้องยืนยันว่าการทดลองกับบุคคลนอกทีมอยู่ภายใต้การอนุมัติจริยธรรมที่มีอยู่ [ต้องตรวจ]
- บันทึกตามขั้นตอนมาตรฐาน แล้วออกรายงานด้วย `Tools/s1_session_report.py` เก็บแยกจากข้อมูลวิจัย
- เกณฑ์มี 8 ข้อตามที่เจ้าของงานกำหนด ส่วนเวลาให้บันทึกตามจริงโดยไม่ใช้เป็นเกณฑ์ผ่าน
- จุดที่ติดให้จัดเป็น 4 กลุ่ม: สื่อหรือคำสั่งไม่ชัด / กลไกหรือ UI บกพร่อง / ยังแก้โจทย์ไม่ได้ / เหตุอื่น เช่น ไม่สบาย
- ทำเสร็จได้ไม่ได้แปลว่าสื่อเข้าใจง่าย และทำไม่ทันก็ไม่ได้แปลว่าสื่อไม่ผ่าน

### G3. Answer leak (Q21)

ชั้นที่ 1 checklist ทีละหน้า ทีละภาพ และทีละเฟรมของวิดีโอ ตามรายการของเจ้าของงาน และเพิ่มเติมดังนี้
- **[หลักฐาน]** RAM DDR4 (M01–M03) เป็นสีเขียว ส่วน DDR5 (M04–M05) สีเข้ม ส่วน spec §5.4 บอกว่า "สีไม่เป็นรหัสคำตอบ" สีจึงแยกชนิด DDR4/DDR5 ได้แต่ไม่ได้แยกคำตอบ เพราะ M03 ก็เขียว ต้องดูให้แน่ใจว่า demonstration part ไม่ใช้สีหรือรูปทรงที่เหมือน M01/M02 เพียงคู่เดียว
- ต้องไม่มีภาพที่เห็นตำแหน่งตัวเลือกบนโต๊ะ (Q13)
- Task B: ตรวจว่าภาพ เสียงพากย์ และความยาว chapter ของแต่ละ Area ไม่ต่างกันจนชี้นำ ข้อนี้รวมการนับคำและวินาทีด้วย

ชั้นที่ 2 blind review ผู้ตรวจที่ไม่รู้เฉลยบันทึกจุดที่ทำให้รู้คำตอบโดยไม่ต้องค้นหาหรือเปรียบเทียบ พร้อมเหตุผล การเทียบ W2 กับฉลากจนรู้ว่าชิ้นไหนถูกไม่นับเป็น leak

### G4. Essential unit table (Q22)

- script สร้างตาราง: หนึ่งแถวต่อหนึ่ง unit × 4 format × 2 ภาษา แต่ละช่องมีข้อความจริง ตำแหน่ง (หน้า/การ์ด/ภาพ/chapter) และช่วงเวลาวิดีโอ พร้อมข้อความเสียงพากย์
